_Repository_ (repo) adalah tempat penyimpanan proyek yang berisi file, kode program, dan riwayat perubahan.

Pada workshop EXPECTIK/TIKMENGAJAR 2026, para mahasiswa diajarkan apa itu Git, GitHub, konsep version control, dll. Workshop di bawa oleh Nugi Farhan yang sudah memiliki pengalaman selama kurang lebih 6 tahun di bidang UX (_user experience_), termasuk di perusahaan _Grab._

_Prompt engineering_ adalah pendekatan dimana seorang pengembang (_developer_) memanfaatkan AI untuk mendesain dan membuat program dengan instruksi khusus. Contoh AI yang dapat digunakan dalam _Prompt engineering_ adalah _ChatGPT_ (OpenAI), _Claude_ (Anthropic), _Gemini_ (Google), _Deepseek_, dan _Grok_ (xAI).

_Version control_ adalah praktik yang dimana setiap terjadi perubahan pada sistem, aplikasi, ataupun _repository._ Aplikasi yang digunakan untuk _version control_ adalah _GitHub_, _Git_, _GitLab_. _Git_ digunakan untuk _version control_ secara lokal, sedangkan _GitHub_ untuk _version control_ secara online.

_Git_ memiliki perintah yang dijalankan di _Command Prompt_, seperti:
| Perintah | Kegunaan |
|----------|----------|
| `git init` | Membuat _repository_ (repo) baru |
| `git clone <url>` | Menjiplak _repository_ yang sudah ada |
| `git add <file>` | Menambahkan file atau perubahan yang belum dilacak |
| `git --version` | Mengecek versi _Git_ yang terinstal di sistem |
